Print Options

📄 Left + Right Pages

Left page: days 1–12 + staff names + trade column. Right page: days 13–end + Remarks only (no repeated name columns), for maximum signature width. Suitable for binding.

💡 If the right-side page's rows don't line up with the left-side page's rows once printed, nudge this up or down (mm) and regenerate — positive pushes the right page's content down, negative pulls it up.

💡 Open Book previews the register in a new browser tab — use that tab's own print (Ctrl+P / ⌘P) to print or save as PDF. Download Register saves the .html file to your device instead. Either way: Paper A4, Margins None, Background graphics on.
